What the last 90 days show

  1. The Maintenance Purge is the task that gets skipped. On 509 printer-days the printer asked for a purge, the operator put it off (Remind later, or the prompt kept repeating), and no purge cycle ran that day.
  2. CA keeps up; PA and MX mostly don't. The CA Rhotex 325 ran a purge on 20 of its 25 prompt days, and the CA P5 Tex purges so often (53 of 72 days) that the prompt never fired. Rhotex 325-1 MX ran a purge on 4 of 81 prompt days; P5 Tex-1 MX on 4 of 60.
  3. Rhotex 325-1 and 325-2 in MX also put off Inspect Print Plane on 59 and 49 days. Rhotex 325-2 MX printed a nozzle test pattern on only 6 of 62 working days, where every other printer was near daily.
  4. The floor sign-off sheet doesn't catch it. On 221 of those 509 skipped-purge days, operators still signed off tasks for that printer in the Machine Maintenance Log.

Purge every 24 hrs · nozzle check before work

One column per day, two stripes: top = purge, bottom = nozzle check. Purge and head test (nozzle check): no more than 24 hours between them. MX runs 24 hours, 7 days: every hour counts, even when a printer is down, so the heads keep flowing. CA and PA: hours of runtime count (printing, a head test or loading media), so a weekend counts only when the plant worked it. Nozzle check also at every startup (first work after 4+ quiet hours) before printing begins, allowing the hour for power-on and ink heating. A stray message (a prompt answered at night, a standby warning) is not a startup. Hover a day for a purge-before-work warning (warning only, not in the counts): the Durst manuals ask for the purge daily before starting work, so the day's first startup is checked for a purge before work began. How "done" and "put off" are read

Rhotex 325: the printer logs each prompt as "done" or "Remind later". P5 350 / P5 Tex: the printer logs the on-screen prompt, and when the operator taps Execute it logs the task again with a separate "done" ID. A prompt with no Execute that day counts as put off. A purge also counts as done when a purge cycle ran the same day.

Block colour in Daily status: for the purge, only the 24-hour rule counts (red = no purge in 24 hours, amber = purged late), whether or not the printer showed its Maintenance Purge reminder. The P5 Tex printers rarely show it. The hover box says whether the printer asked. The purge cards and the trend chart above still count the printer's reminders.

Purge and nozzle check (WS Display policy, Nov 2026): a printer can start production once a nozzle check shows the heads are good, and the purge can run later in the day. Nozzle check: at every startup (the first activity after 4 or more hours with nothing logged: overnight, weekends, downtime), a test pattern must be printed before work; late when the printer was active more than an hour before it. Purge: at least once every 24 hours, counted from the last purge cycle Durst Analytics recorded; late when the printer kept working more than 24 hours after it, not counting the hour before the next purge. For reference, the Durst manuals ask for a purge cycle daily before starting work (once every 24 hours in 24-hour operation), then a test image: Rhotex 325 §H.14.2.1, P5 Tex §H.17.2.1, P5 350 §H.15.2.1.
